
# Cobox Technologies Portfolio

A production-ready, fully responsive React + Vite portfolio website for Cobox Technologies.

## Features
- Dark blue + green futuristic theme
- Animated 3D globe hero section (Three.js)
- Scroll-triggered animations (Framer Motion, GSAP)
- Fully responsive, enterprise-grade design
- Glassmorphism cards, glowing elements
- Sticky animated navbar, scroll progress indicator, back-to-top button
- Modern contact form with validation
- SEO meta tags, accessibility, optimized performance

## Sections
- Hero
- Services
- Impact Stats
- Case Studies
- Process
- Testimonials
- Technologies
- Contact
- Footer

## Tech Stack
- React (latest)
- Vite
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Three.js
- React Icons

## Setup
1. Install dependencies:
	```bash
	npm install
	```
2. Start development server:
	```bash
	npm run dev
	```

## Customization
- Replace placeholder images in `src/assets`.
- Update company info and links in `Footer.jsx`.
